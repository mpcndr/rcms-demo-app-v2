# RCMS Demo App

Prototype สำหรับนำเสนอโครงการ **Registration and Capital Monitoring System (RCMS)**
ความร่วมมือระหว่างกระทรวงอุตสาหกรรมและการค้า (MOIC) กับธนาคารส่งเสริมการเกษตร (APB)

แอปยังเป็น `index.html` ไฟล์เดียว vanilla JS เหมือนเดิม แต่ตอนนี้รันผ่าน Vite
(ดู `package.json`) เพื่อให้ import npm package จริงได้ (เช่น Leaflet สำหรับแผนที่)

```
npm install
npm run dev      # dev server ที่ http://localhost:5173
npm run build    # build ไปที่ dist/
npm run preview  # serve dist/ ไว้เช็คก่อน deploy
```

ต้องมีเน็ตตอน `npm install` ครั้งแรก และตอนรัน (โหลดฟอนต์จาก Google Fonts + tile แผนที่จาก OpenStreetMap —
ถ้าไม่มีเน็ต ฟอนต์จะ fallback เป็นฟอนต์ระบบ แต่แผนที่จะไม่ขึ้น)

## ระยะที่ 1 — สิ่งที่มีใน `phase1`

Flow หลักที่เดินได้จริงตั้งแต่ต้นจนจบ:

1. เข้าสู่ระบบ + MFA (OTP)
2. แดชบอร์ดติดตามทุน — กราฟ 3 ชุด (สัดส่วนสถานะ / ทุนครบกำหนด vs ชำระจริง / จำนวนเกินกำหนดย้อนหลัง 12 เดือน)
3. ทะเบียนวิสาหกิจ — ค้นหาและกรองตามสถานะ แขวง ISIC
4. รายละเอียดวิสาหกิจ — ไทม์ไลน์การประกอบทุน 1 ปี + งวด 30% / 70%
5. บันทึกการชำระทุน — เงินสด / ทรัพย์สิน พร้อมแนบเอกสาร
6. ตรวจทานโดย Reviewer
7. อนุมัติ + ลงลายเซ็นดิจิทัล (MFA ซ้ำ)
8. ใบรับรองการฝากทุน — Print Preview + ฉบับจริง/สำเนา (Watermark)
9. ประเมินทรัพย์สิน — In-network / Out-of-network
10. ตั้งค่าระบบ — ค่าธรรมเนียมขั้นบันได / ผู้ใช้งาน RBAC / API Log
11. มุมมองมือถือผู้ประกอบการ + การแจ้งเตือน

### บทบาทที่สลับได้ (แถบบนสุด)

| ปุ่ม | บทบาท | สิทธิ์ |
|---|---|---|
| 1 · เจ้าหน้าที่ APB | Checker | บันทึกการชำระทุน แนบเอกสาร ส่งตรวจทาน |
| 2 · ผู้ตรวจทาน | Reviewer | ตรวจความถูกต้อง ส่งต่อ หรือตีกลับ |
| 3 · ผู้อนุมัติ | Approver | อนุมัติ + ลงลายเซ็นดิจิทัล (ต้อง MFA) |
| ผู้ประกอบการ | Business Owner | ดูสถานะทุนของตัวเอง ชำระเงิน รับแจ้งเตือน |

### เส้นทางสาธิต 90 วินาที

```
พิมพ์ OTP 6 หลัก → เข้าสู่ระบบ
→ กดการ์ด "ชำระบางส่วน"
→ กดแถวแรก (ລາວກະສິກຳພັດທະນາ)
→ บันทึกการชำระทุน → แนบไฟล์ → ส่งตรวจทาน
→ สลับเป็น "2 · ผู้ตรวจทาน" → เปิดงาน → ส่งต่อผู้อนุมัติ
→ สลับเป็น "3 · ผู้อนุมัติ" → เปิดงาน → ลงลายเซ็น (ใส่ OTP)
→ ดูแดชบอร์ด: ตัวเลข "ชำระครบ" ขยับจาก 742 เป็น 743
```

### Business rule ที่ฝังไว้จริง (ลองกดให้ error ดูได้)

- งวดแรกต้องไม่ต่ำกว่า 30% ของทุนจดทะเบียน
- ยอดที่บันทึกต้องไม่เกินยอดคงเหลือ
- ต้องแนบเอกสารหลักฐานอย่างน้อย 1 ไฟล์
- ปุ่มออกใบรับรองจะกดไม่ได้จนกว่าทุนจะชำระครบ
- ผู้อนุมัติจะไม่เห็นงานจนกว่าจะผ่านการตรวจทานก่อน

## ระยะที่ 2 — สิ่งที่จะเพิ่มใน `phase2`

ยังไม่ได้ทำ (จะทยอยเพิ่มใน branch นี้)

- ฟอร์มยื่นคำร้องแบบ Dynamic Form — เปลี่ยนช่องกรอกตามประเภทธุรกิจ
- อัปโหลดเอกสาร + OCR อ่านบัตรประชาชน/พาสปอร์ต
- ออกใบทะเบียนวิสาหกิจดิจิทัล
- ส่งข้อมูลให้ MOF, ธนาคารกลาง และ 15 กระทรวง
- External Web Portal สำหรับหน่วยงานภายนอก
- Migrate ข้อมูลจาก eBRS
